Quiz 1 (Weeks 1–4)
1. What is the resulting output and data type of `c` in the following snippet?
a = 5 b = 2.0 c = a / b
2. What will be the printed output of the following code?
x = 10 y = 20 if (x == 10) & (y == 5): print("Condition A") elif (x == 10) | (y == 5): print("Condition B") else: print("Condition C")
3. How many total times will the print statement execute in this loop?
count = 0 while count < 4: print(count) count += 1
4. Given the dictionary structure below, which statement correctly extracts the grade `'A'`?
student = { 'name': 'John', 'grade': {'python': 'A', 'AI': 'B'} }
5. What is the value of `item` after executing this list operation?
arr = [10, 20, 30, 40] arr.insert(0, 99) item = arr[1]
6. What happens if you attempt to modify an element of a tuple, e.g., `cars[0] = "Honda"`?
cars = ("Mercedes", "Ferrari", "Toyota") cars[0] = "Honda"
7. What is the correct slice syntax to output `"World!"` from `msg = "Hello, World!"`?
msg = "Hello, World!"
8. In Object-Oriented Programming, what is the purpose of `self` in Python class methods?
class Car: def __init__(self, make): self.make = make
9. What will be the shape of the array generated by `np.linspace(0, 100, 5)`?
import numpy as np linear_space = np.linspace(0, 100, 5)
10. What operator is used in NumPy for true matrix multiplication (row-by-column)?
